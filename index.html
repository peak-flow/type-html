What these numbers mean

Each operation uses 15 measured runs after 3 warmups. The automatic comparison uses the same short fixture, one editor at a time, and alternates which runs first. Hover over a timing for its 95th percentile.

These are warm-cache browser operations, not backend or network benchmarks. Sub-millisecond differences are noisy. Startup download and script parsing are excluded from the operation timings; each editor page shows its own page-ready time. More features also mean more work, so speed alone is not a quality score.
